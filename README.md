# TTRPG Soundboard

A soundboard for running tabletop RPG sessions.

| App | Folder | Status |
| --- | --- | --- |
| **Mac** (Electron) | [`soundboard-mac/`](soundboard-mac/) | Sounds, YouTube clipping and full-audio saving, ambience layers, Bashes |
| **iPad / iPhone** (SwiftUI) | [`soundboard-ipad/`](soundboard-ipad/) | Sounds, YouTube clipping and full-audio saving, ambience layers (Bashes coming) |

The built-in ambience loops (rain, campfire, wind and so on) are generated by [`tools/generate-ambience.py`](tools/generate-ambience.py) and shared by both apps.

## Quick start (Mac)

```bash
brew install node yt-dlp
cd soundboard-mac
npm install
npm start
```

See each app's README for details.
